# Data

This folder contains the synthetic datasets used in CLD-IR-0002.

- `cloudora_msgtrace_logs.csv` → `CloudoraMsgTrace_CL`
- `cloudora_signin_logs.csv` → `CloudoraSignIn_CL`

The query pack uses these datasets to scope the campaign, identify clicks and credential submissions, and correlate them with subsequent sign-in activity.

All timestamps are UTC and all records are synthetic training data.
